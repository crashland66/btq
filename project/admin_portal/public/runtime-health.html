Runtime Health

V1 describes the health surfaces the protected portal can expose without becoming an operational writer.

Q

Queue Backlog

Read-only count of queue files waiting on the Mac runtime.

R

Review State

Pending candidates, approved drafts, and staging status summaries.

L

Recent Logs

Warnings and errors from Mac-side runtime log tails.

U

Latest Uploads

VPS field-capture upload visibility after protected sync or proxy.

Read-Only Contract

Health views may read status JSON from the protected Mac dashboard or static exports. They must not call queue processors, import captures, approve candidates, publish summaries, or write vault files.

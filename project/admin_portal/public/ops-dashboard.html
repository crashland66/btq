Ops Dashboard

V1 links to the runtime read-only dashboard instead of proxying it through the public admin hostname.

Chosen V1 Approach

Use a protected link to http://processing-node.example:8765/. The dashboard remains hosted by the Mac runtime, and the VPS admin shell does not become a runtime authority.

Reverse proxying can be enabled later only after the admin hostname is protected by Cloudflare Access, Tailscale-only reachability, Caddy basic auth, or an equivalent control.

Proxy Guardrails

  • No processor execution route exposed through the admin shell.
  • No queue staging, approval, or publish route in V1.
  • The processing node remains the runtime and processing authority.

# Web Review Notes

This skill converts a set of conversion-focused web design principles into a reusable website review prompt.

The prompt is intentionally blunt, but the output should remain useful: concrete fixes, conservative claims, no invented evidence, and no dark patterns.

Version notes:

- `v1` is the compact initial structure.
- `v2` is the current strict markdown reviewer with scoring, tiering, cut list, roadmap, and AI-ready rewrite block.

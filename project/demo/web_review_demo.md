# Web Review Demo Input

URL: https://demo.local/booking

Demo site description:

The homepage is for a local appointment-based service business. The first viewport says "Experience Better Service" but does not clearly say what the business does, who it serves, or what outcome a visitor can expect.

The site loads slowly on mobile because the hero uses a large background video and several decorative animations. Important content appears late after the initial animation finishes.

There are no structured endpoints, no API documentation, and no machine-readable booking metadata. The only contact path is a generic "Get Started" button that opens a long form.

The booking flow is unclear. Visitors cannot tell whether they are requesting a quote, booking an appointment, joining a waitlist, or starting a sales conversation. Pricing is not shown, service area is vague, and there are no real team photos or customer proof.
